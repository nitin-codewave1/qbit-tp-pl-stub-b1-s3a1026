# TC-006-07: Editing and saving shows updated content

**Story:** [[US-006-03]]
**Module:** edit an existing note's title or body using the web editor
**Kind:** ui
**Covered by:** TC-006-05

## Preconditions
Existing note open in editor

## Expected Result
PATCH called and updated content shown

## Acceptance Criteria
- web_app:AC-006-03-01: Given an existing note is opened in the editor, when the user changes the title or body and saves, then the web app calls PUT/PATCH /notes/{id} and shows the updated content

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Open editor | navigate | `/notes/:id/edit` |  |
| 2 | Change body | fill | `getByLabel('Body')` | Changed body |
| 3 | Save | click | `getByRole('button', {name: 'Save'})` |  |
| 4 | Updated content shown | assert_text | `data-testid=US-006-03-note-body` | Changed body |
