# TC-006-29: Notes list with pinned first, sort and count

**Story:** [[US-006-01]]
**Module:** view a list of all notes in the web app
**Kind:** ui

## Preconditions
Notes exist including a pinned one

## Expected Result
Titles/status rendered, pinned first with pin icon, sort control default Newest first, live result count matches

## Acceptance Criteria
- web_app:AC-006-01-01: Given notes exist in notes_api, when the notes list page loads, then the web app calls GET /notes, renders each note's title and status, renders pinned notes first with a pin icon, shows a sort control above the list (Newest first, Oldest first, Title A-Z) with Newest first selected by default, and shows a live result count above the list equal to the number of notes listed
