# TC-006-04: Submit editor creates note

**Story:** [[US-006-02]]
**Module:** create a new note using the web editor
**Kind:** ui
**Covered by:** TC-006-04

## Preconditions
Title and body entered

## Expected Result
POST /notes called and app navigates to saved note

## Acceptance Criteria
- web_app:AC-006-02-01: Given a title and body are entered in the editor, when the user submits, then the web app calls POST /notes and navigates to the saved note
