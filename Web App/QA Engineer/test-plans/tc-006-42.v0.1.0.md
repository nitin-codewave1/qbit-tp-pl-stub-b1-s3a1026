# TC-006-42: [error] Locked account shows 15-minute lockout and disables submission

**Story:** [[US-006-05]]
**Module:** log in from the web app by requesting an email one-time code and entering it on a code-entry screen
**Kind:** ui
**Covered by:** TC-006-72

## Preconditions
Five wrong codes entered; verify returns locked-account error

## Expected Result
Lockout error stating 15 minutes; code submission disabled

## Acceptance Criteria
- web_app:AC-006-05-02: Given the user has entered a wrong code 5 attempts times, when the verify-code endpoint reports the account is locked, then the web app shows a lockout error stating the account is locked for 15 minutes and disables code submission
