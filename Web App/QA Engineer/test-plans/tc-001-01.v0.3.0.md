# TC-001-01: POST /notes is called

**Story:** [[US-001-01]]
**Module:** create a new note via the API with title and body text

## Preconditions
a valid title and body payload

## Expected Result
API returns 201 with the created note including its id

## Acceptance Criteria
Given a valid title and body payload, when POST /notes is called, then API returns 201 with the created note including its id
Given a payload missing required title field, when POST /notes is called, then API returns 400 with a validation error and no note is created
Given a body field at the maximum allowed length, when POST /notes is called, then API returns 201 and stores the full body without truncation

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Send POST /notes with a valid title and body payload | navigate | `/notes` | POST {title, body} |
| 2 | Verify response is 201 with the created note including its id | assert_text | `body` | 201 created note with id |
