# TC-001-06: [edge] Two quick successive updates, last write wins

**Story:** [[US-001-02]]
**Module:** edit an existing note's title or body via the API
**Kind:** ui
**Covered by:** TC-005-07

## Preconditions
An existing note open in editor

## Expected Result
Last accepted write wins and fields are not corrupted

## Acceptance Criteria
- web_app:AC-001-02-03: Given a concurrent edit request on the same note, when two update requests are sent in quick succession, then the last accepted write wins and no fields are partially corrupted
