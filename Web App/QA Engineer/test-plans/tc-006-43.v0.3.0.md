# TC-006-43: [error] Expired code or resend limit reached

**Story:** [[US-006-05]]
**Module:** log in from the web app by requesting an email one-time code and entering it on a code-entry screen
**Kind:** ui
**Covered by:** TC-006-71

## Preconditions
Code older than 10 minutes, or 3 resends in 10 minutes reached

## Expected Result
Expired-code error with request-new-code option, or resend-limit error

## Acceptance Criteria
- web_app:AC-006-05-03: Given the code was issued more than 10 minutes ago, or the resend limit of 3 resends per 10 minutes has been reached, when the user submits the code or asks for a new code, then the web app shows an expired-code error with an option to request a new code, or a resend-limit error when no more resends are allowed
