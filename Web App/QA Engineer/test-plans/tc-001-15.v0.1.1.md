# TC-001-15: [edge] Client-supplied timestamps ignored

**Story:** [[US-001-06]]
**Module:** have each note's creation and last-modified timestamps tracked automatically
**Kind:** ui

## Preconditions
Client submits created_at/updated_at (e.g. 2000-01-01)

## Expected Result
Client timestamps ignored; server time used

## Acceptance Criteria
- web_app:AC-001-06-03: Given a client sends its own created_at or updated_at value, when POST or PATCH is called, then API ignores client-supplied timestamps and uses server time
