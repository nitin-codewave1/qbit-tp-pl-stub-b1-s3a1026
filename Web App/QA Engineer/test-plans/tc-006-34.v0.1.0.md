# TC-006-34: Pin toggle moves row to top with pin icon

**Story:** [[US-006-06]]
**Module:** archive, restore or pin/unpin a note from the web app so that manage note lifecycle and ordering without calling the API directly
**Kind:** ui

## Preconditions
Notes list with an unpinned note

## Expected Result
Pinned flag set via API, row moves to top with pin icon; unpin returns it to sort position

## Acceptance Criteria
- web_app:AC-006-06-03: Given a notes row in the list, when the user clicks its pin toggle, then the web app calls the API to set the note's pinned flag and the row moves to the top with a pin icon (or returns to its sort position when unpinned)
