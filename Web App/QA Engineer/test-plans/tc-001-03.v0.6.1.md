# TC-001-03: [edge] Create note with maximum-length body

**Story:** [[US-001-01]]
**Module:** create a new note via the API with title and body text
**Kind:** ui

## Preconditions
User is signed in; max body length known

## Expected Result
Note is created and full body is stored without truncation

## Acceptance Criteria
- web_app:AC-001-01-03: Given a body field at the maximum allowed length, when POST /notes is called, then API returns 201 and stores the full body without truncation

## Planned Playwright Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Open editor | navigate | `/notes/new` |  |
| 2 | Enter title | fill | `getByLabel('Title')` | Max body |
| 3 | Enter body of maximum allowed length | fill | `getByLabel('Body')` | <max-length body string> |
| 4 | Submit | click | `getByRole('button', {name: 'Save'})` |  |
| 5 | Full body displayed untruncated | assert_text | `data-testid=US-001-01-note-body` | <max-length body string> |
