# TC-006-41: Email one-time code login succeeds

**Story:** [[US-006-05]]
**Module:** log in from the web app by requesting an email one-time code and entering it on a code-entry screen
**Kind:** ui
**Covered by:** TC-006-70

## Preconditions
User on login screen; valid 6-digit code available

## Expected Result
Request-code called, code-entry shown, verify-code signs user in

## Acceptance Criteria
- web_app:AC-006-05-01: Given the user is on the login screen and enters their email address, when they submit the email and then enter a valid 6 digits-digit code on the code-entry screen, then the web app calls the notes_api request-code endpoint, shows the code-entry screen, calls the verify-code endpoint with the entered code and signs the user in
