# TC-006-42: [error] Five wrong codes lock account

**Story:** [[US-006-05]]
**Module:** log in from the web app by requesting an email one-time code and entering it on a code-entry screen
**Kind:** ui
**Covered by:** TC-006-72

## Preconditions
On code-entry screen

## Expected Result
Lockout error for 15 minutes and code submission disabled

## Acceptance Criteria
- web_app:AC-006-05-02: Given the user has entered a wrong code 5 attempts times, when the verify-code endpoint reports the account is locked, then the web app shows a lockout error stating the account is locked for 15 minutes and disables code submission

## Planned Playwright Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Open code entry | navigate | `/login/code` |  |
| 2 | Wrong code (repeat 5 times, submitting each time) | fill | `getByLabel('Code')` | 000000 |
| 3 | Verify | click | `getByRole('button', {name: 'Verify'})` |  |
| 4 | Lockout error 15 minutes | assert_text | `data-testid=US-006-05-error` | 15 minutes |
| 5 | Submit disabled | assert_visible | `getByRole('button', {name: 'Verify'})` | disabled |
