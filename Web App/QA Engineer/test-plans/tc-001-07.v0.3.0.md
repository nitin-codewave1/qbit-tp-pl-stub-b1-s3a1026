# TC-001-07: GET /notes/{id} is called

**Story:** [[US-001-03]]
**Module:** retrieve a single note by its id

## Preconditions
a note exists with a given id

## Expected Result
API returns 200 with the full note content

## Acceptance Criteria
Given a note exists with a given id, when GET /notes/{id} is called, then API returns 200 with the full note content
Given a note id that does not exist or was deleted, when GET /notes/{id} is called, then API returns 404

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Send GET /notes/{id} for an existing note | navigate | `/notes/{id}` | GET |
| 2 | Verify response is 200 with full note content | assert_text | `body` | 200 full note content |
