# TC-006-26: Keyword search keeps sort and updates count

**Story:** [[US-006-04]]
**Module:** search notes using a search box with free-text and tag filters
**Kind:** ui

## Preconditions
User enters keyword; a sort order selected

## Expected Result
Matches in selected sort, sort unchanged, count updated

## Acceptance Criteria
- web_app:AC-006-04-01: Given the user enters a keyword in the search box, when they submit, then the web app calls the search endpoint, renders matching notes in the currently selected sort order (Newest first, Oldest first, or Title A-Z) without changing the sort selection, and updates the live result count above the list to the number of matches
