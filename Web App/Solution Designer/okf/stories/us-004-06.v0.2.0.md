# US-004-06

As a compliance auditor, I want to access a historical log of residency audit results over time, so that demonstrates ongoing compliance for recurring audits, not just the initial pre-launch check. - Given multiple residency audits have been run, when the auditor views the audit history, then each past audit's date, scope, and result are listed - Given no audits have been run yet, when the auditor views the audit history, then an empty state is shown rather than an error - Test case: the auditor views the audit history - Test case: [edge] the auditor views the audit history
