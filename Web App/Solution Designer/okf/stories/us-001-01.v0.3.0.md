# US-001-01

As a Team member drafting a note, I want to create a new note via the API with title and body text, so that reliably persist new notes so create calls return 2xx success. - Given a valid title and body payload, when POST /notes is called, then API returns 201 with the created note including its id - Given a payload missing required title field, when POST /notes is called, then API returns 400 with a validation error and no note is created - Given a body field at the maximum allowed length, when POST /notes is called, then API returns 201 and stores the full body without truncation - Test case: POST /notes is called - Test case: [error] POST /notes is called - Test case: [edge] POST /notes is called
