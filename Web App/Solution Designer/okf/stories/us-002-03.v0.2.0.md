# US-002-03

As a team member searching for a note by keyword, I want to query the search endpoint with free-text terms, so that finds relevant notes quickly, directly measured by the % relevant results KPI. - Given notes exist whose title or body contains the query term, when client calls search endpoint with that term, then API returns 200 with matching notes ranked by relevance within 300ms median - Given a query term that matches no notes, when client calls search endpoint, then API returns 200 with an empty result list, not an error - Given a search request with an empty or missing query parameter, when client calls the search endpoint, then API returns 400 with a validation error message - Test case: client calls search endpoint with that term - Test case: [edge] client calls search endpoint - Test case: [error] client calls the search endpoint
