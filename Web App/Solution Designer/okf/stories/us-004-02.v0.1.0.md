# US-004-02

As a compliance auditor, I want to retrieve a report listing the region of every data store and service used by notes_api, so that enables pre-launch audits to confirm 100% EU-only data storage. - Given notes_api infrastructure is deployed, when the auditor requests the residency report, then the report lists each data store/service with its region and confirms all are EU - Given a service's region is undetermined, when the report is generated, then that service is flagged as unverified rather than assumed compliant - Test case: the auditor requests the residency report - Test case: [edge] the report is generated
