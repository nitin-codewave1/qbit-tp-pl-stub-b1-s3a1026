# US-005-06

As a backend developer, I want to block any endpoint or parameter designed solely to support a native mobile client (e.g. device push tokens), so that keeps the API free of mobile-specific features since no mobile app is in scope. - Given the API endpoints are reviewed, when checked for mobile-only parameters, then none are present - Given a request includes a device push-token field, when submitted to any endpoint, then the API returns 400 indicating the field is unsupported - Test case: checked for mobile-only parameters - Test case: [error] submitted to any endpoint
