# US-005-04

As a QA engineer, I want to run an automated scope-compliance test suite against every build, so that gives a measurable count of endpoints/features vs. brief scope on each release. - Given a build is produced, when the scope-compliance suite runs, then it reports exactly 5 capability groups with zero extras - Given an endpoint exists that technically maps to 'search' but accepts attachment-filter parameters, when the suite inspects its parameters, then it flags the parameter as out-of-scope - Test case: the scope-compliance suite runs - Test case: [edge] the suite inspects its parameters
