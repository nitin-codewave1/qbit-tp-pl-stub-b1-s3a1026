# US-003-05

As a developer integrating with notes_api, I want to edit or tag a note regardless of its archive state, so that ensure archiving never causes data loss or blocks legitimate operations. - Given an archived note exists, when client sends an edit or tag update request for it, then API applies the update and returns 200, archive status unchanged - Given an archived note is updated, when update completes, then note remains archived and no data fields are lost - Test case: client sends an edit or tag update request for it - Test case: [edge] update completes
