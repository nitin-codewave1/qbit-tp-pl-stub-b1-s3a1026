# US-001-02

As a Team member updating shared notes, I want to edit an existing note's title or body via the API, so that keep notes accurate without data loss, supporting reliable edit success rate. - Given an existing note id and updated fields, when PUT/PATCH /notes/{id} is called, then API returns 200 with the updated note reflecting changes - Given a note id that does not exist, when PUT/PATCH /notes/{id} is called, then API returns 404 and no data is altered - Given a concurrent edit request on the same note, when two update requests are sent in quick succession, then the last accepted write wins and no fields are partially corrupted - Test case: PUT/PATCH /notes/{id} is called - Test case: [error] PUT/PATCH /notes/{id} is called - Test case: [edge] two update requests are sent in quick succession
