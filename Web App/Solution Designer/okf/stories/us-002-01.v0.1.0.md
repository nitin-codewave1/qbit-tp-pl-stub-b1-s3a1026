# US-002-01

As a team member tagging notes, I want to add one or more tags to a note via the API, so that notes become categorized so later searches return relevant results, improving the QA relevance KPI. - Given an existing note and valid tag strings, when client sends a request to add tags to the note, then API returns 200 with the note's updated tag list - Given an existing note with no tags, when client submits a duplicate of an existing tag, then API deduplicates and returns the tag list without duplicates - Given a note id that does not exist, when client sends a tag-add request to that id, then API returns 404 with an error message - Test case: client sends a request to add tags to the note - Test case: [edge] client submits a duplicate of an existing tag - Test case: [error] client sends a tag-add request to that id
