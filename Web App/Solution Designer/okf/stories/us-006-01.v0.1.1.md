# US-006-01

As a Team member, I want to view a list of all notes in the web app, so that browse existing notes without calling the API directly. - Given notes exist in notes_api, when the notes list page loads, then the web app calls GET /notes, renders each note's title and status, renders pinned notes first with a pin icon, shows a sort control above the list (Newest first, Oldest first, Title A-Z) with Newest first selected by default, and shows a live result count above the list equal to the number of notes listed - Given no notes exist yet, when the notes list page loads, then the web app shows an empty-state message and a result count of 0 instead of an error
