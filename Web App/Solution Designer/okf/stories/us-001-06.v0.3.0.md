# US-001-06

As a Team member relying on note integrity, I want to have each note's creation and last-modified timestamps tracked automatically, so that trust the API as a reliable system-of-record with no data loss. - Given a note is created, when POST /notes succeeds, then the response includes a created_at timestamp set by the server - Given a note is edited, when PATCH /notes/{id} succeeds, then the response includes an updated_at timestamp reflecting the edit time - Given a client sends its own created_at or updated_at value, when POST or PATCH is called, then API ignores client-supplied timestamps and uses server time - Test case: POST /notes succeeds - Test case: PATCH /notes/{id} succeeds - Test case: [edge] POST or PATCH is called
