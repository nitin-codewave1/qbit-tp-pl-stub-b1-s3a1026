# US-002-04

As a team member narrowing results by category, I want to filter search results by one or more tags, so that quickly locates notes within a known category, improving relevance KPI for tag-based queries. - Given notes tagged with a specific tag exist, when client calls search endpoint with that tag as a filter parameter, then API returns 200 with only notes containing that tag - Given notes exist matching both a keyword and a tag filter, when client calls search with both parameters combined, then API returns 200 with notes satisfying both conditions
