# US-002-02

As a team member removing an outdated tag, I want to remove a tag from a note via the API, so that search results stay accurate as note categorization evolves, protecting relevance KPI. - Given a note with an existing tag, when client sends a request to remove that tag, then API returns 200 and the tag is no longer in the note's tag list - Given a note that does not have the specified tag, when client requests removal of that tag, then API returns 415 indicating tag not found on note - Test case: client sends a request to remove that tag - Test case: [error] client requests removal of that tag
