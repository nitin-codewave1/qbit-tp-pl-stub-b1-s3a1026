# US-001-05

As a Developer building client integrations, I want to receive clear field-level validation errors when note data is malformed, so that quickly fix bad requests, increasing the proportion of calls that return 2xx. - Given a request with an invalid data type for a field, when POST or PATCH /notes is called, then API returns 400 with a message naming the invalid field - Given an empty JSON body, when POST /notes is called, then API returns 400 identifying all missing required fields - Test case: [error] POST or PATCH /notes is called - Test case: [edge] POST /notes is called
