# US-003-03

As a team member managing their workspace, I want to list only archived notes via the API, so that separate old notes from active ones, confirming archive lifecycle works correctly. - Given some notes are archived and some are active, when client requests the list filtered by archived status, then API returns only archived notes with 200 - Given no notes are currently archived, when client requests the archived list, then API returns 200 with an empty list, not an error - Test case: client requests the list filtered by archived status - Test case: [edge] client requests the archived list
