# US-001-03

As a Developer integrating with the notes API, I want to retrieve a single note by its id, so that confirm notes persisted correctly, supporting reliability as system-of-record. - Given a note exists with a given id, when GET /notes/{id} is called, then API returns 200 with the full note content - Given a note id that does not exist or was deleted, when GET /notes/{id} is called, then API returns 404 - Test case: GET /notes/{id} is called - Test case: [error] GET /notes/{id} is called
