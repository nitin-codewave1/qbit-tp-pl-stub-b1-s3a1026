# US-004-04

As a compliance auditor, I want to verify that any third-party services or dependencies used by notes_api also store/process data within the EU, so that closes gaps in the residency chain that could fail the compliance KPI. - Given notes_api depends on a third-party service, when the auditor reviews the service's data processing location, then the location is documented as EU-resident - Given a third-party service's data residency cannot be confirmed, when the audit is run, then the dependency is flagged for remediation before launch - Test case: the auditor reviews the service's data processing location - Test case: [edge] the audit is run
