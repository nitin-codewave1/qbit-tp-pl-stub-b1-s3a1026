# US-004-01

As a platform operations engineer, I want to configure the database and application hosting region to an EU-only region at provisioning time, so that guarantees EU-only data storage, directly driving the % of infrastructure audits confirming EU residency. - Given a new deployment environment is being provisioned, when infrastructure is created, then database and compute resources are located in an approved EU region - Given an attempt to provision a resource in a non-EU region, when the provisioning request is submitted, then the request is rejected and logged - Test case: infrastructure is created - Test case: [error] the provisioning request is submitted
