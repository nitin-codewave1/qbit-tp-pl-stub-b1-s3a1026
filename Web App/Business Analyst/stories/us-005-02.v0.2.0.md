# US-005-02: reject any request payload containing file/binary attachment data on the create or edit endpoints

## Definition

As a **backend developer**, I want to **reject any request payload containing file/binary attachment data on the create or edit endpoints**, so that **prevents attachment features from creeping into the minimal-scope build**.

**Epic:** [[EP-005]]

## Acceptance Criteria
- [[AC-005-02-01]] — Given a note is created with only title, body, and tags, when the request is submitted, then the note is saved successfully
- [[AC-005-02-02]] — Given a request includes a multipart/form-data file field or binary attachment, when the request hits create or edit endpoint, then the API returns 400 with an 'attachments not supported' error
