# US-001-05: receive clear field-level validation errors when note data is malformed

## Definition

As a **Developer building client integrations**, I want to **receive clear field-level validation errors when note data is malformed**, so that **quickly fix bad requests, increasing the proportion of calls that return 2xx**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-05-01]] — Given a request with an invalid data type for a field, when POST or PATCH /notes is called, then API returns 400 with a message naming the invalid field
- [[AC-001-05-02]] — Given an empty JSON body, when POST /notes is called, then API returns 400 identifying all missing required fields
