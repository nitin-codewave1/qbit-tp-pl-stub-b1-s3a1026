# US-001-01: create a new note via the API with title and body text

## Definition

As a **Team member drafting a note**, I want to **create a new note via the API with title and body text**, so that **reliably persist new notes so create calls return 2xx success**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-01-01]] — Given a valid title and body payload, when POST /notes is called, then API returns 201 with the created note including its id
- [[AC-001-01-02]] — Given a payload missing required title field, when POST /notes is called, then API returns 400 with a validation error and no note is created
- [[AC-001-01-03]] — Given a body field at the maximum allowed length, when POST /notes is called, then API returns 201 and stores the full body without truncation
