# US-004-06: access a historical log of residency audit results over time

## Definition

As a **compliance auditor**, I want to **access a historical log of residency audit results over time**, so that **demonstrates ongoing compliance for recurring audits, not just the initial pre-launch check**.

**Epic:** [[EP-004]]

## Acceptance Criteria
- [[AC-004-06-01]] — Given multiple residency audits have been run, when the auditor views the audit history, then each past audit's date, scope, and result are listed
- [[AC-004-06-02]] — Given no audits have been run yet, when the auditor views the audit history, then an empty state is shown rather than an error
