# US-001-06: have each note's creation and last-modified timestamps tracked automatically

## Definition

As a **Team member relying on note integrity**, I want to **have each note's creation and last-modified timestamps tracked automatically**, so that **trust the API as a reliable system-of-record with no data loss**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-06-01]] — Given a note is created, when POST /notes succeeds, then the response includes a created_at timestamp set by the server
- [[AC-001-06-02]] — Given a note is edited, when PATCH /notes/{id} succeeds, then the response includes an updated_at timestamp reflecting the edit time
- [[AC-001-06-03]] — Given a client sends its own created_at or updated_at value, when POST or PATCH is called, then API ignores client-supplied timestamps and uses server time
