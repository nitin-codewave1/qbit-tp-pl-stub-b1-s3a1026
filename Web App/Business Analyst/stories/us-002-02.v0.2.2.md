# US-002-02: remove a tag from a note via the API

## Definition

As a **team member removing an outdated tag**, I want to **remove a tag from a note via the API**, so that **search results stay accurate as note categorization evolves, protecting relevance KPI**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-02-01]] — Given a note with an existing tag, when client sends a request to remove that tag, then API returns 200 and the tag is no longer in the note's tag list
- [[AC-002-02-02]] — Given a note that does not have the specified tag, when client requests removal of that tag, then API returns 415 indicating tag not found on note
