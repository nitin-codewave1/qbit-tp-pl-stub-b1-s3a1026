# US-006-02: create a new note using the web editor

## Definition

As a **Team member**, I want to **create a new note using the web editor**, so that **add notes without needing to call the API manually**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-02-01]] — Given a title and body are entered in the editor, when the user submits, then the web app calls POST /notes and navigates to the saved note
- [[AC-006-02-02]] — Given the title field is left empty, when the user submits, then the web app shows the API's validation error inline without creating a note
- [[AC-006-02-03]] — Given the create request succeeds, when the response is received, then the note's server-set created_at is reflected in the UI
