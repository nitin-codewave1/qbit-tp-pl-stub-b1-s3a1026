# US-005-03: ensure no WebSocket, SSE, or polling-for-live-updates endpoints are exposed

## Definition

As a **API tech lead**, I want to **ensure no WebSocket, SSE, or polling-for-live-updates endpoints are exposed**, so that **keeps the build free of real-time collaboration features not in brief scope**.

**Epic:** [[EP-005]]

## Acceptance Criteria
- [[AC-005-03-01]] — Given the API's route registry is inspected, when checked for protocol types, then only standard HTTP request/response endpoints are present
- [[AC-005-03-02]] — Given a pull request adds a WebSocket or SSE route, when CI scope-guardrail check runs, then the check fails and blocks merge
