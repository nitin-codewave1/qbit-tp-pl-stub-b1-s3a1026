# US-001-03: retrieve a single note by its id

## Definition

As a **Developer integrating with the notes API**, I want to **retrieve a single note by its id**, so that **confirm notes persisted correctly, supporting reliability as system-of-record**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-03-01]] — Given a note exists with a given id, when GET /notes/{id} is called, then API returns 200 with the full note content
- [[AC-001-03-02]] — Given a note id that does not exist or was deleted, when GET /notes/{id} is called, then API returns 404
