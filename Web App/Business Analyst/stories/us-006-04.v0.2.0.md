# US-006-04: search notes using a search box with free-text and tag filters

## Definition

As a **Team member**, I want to **search notes using a search box with free-text and tag filters**, so that **quickly find relevant notes from the browser**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-04-01]] — Given the user enters a keyword in the search box, when they submit, then the web app calls the search endpoint, renders matching notes in the currently selected sort order (Newest first, Oldest first, or Title A-Z) without changing the sort selection, and updates the live result count above the list to the number of matches
- [[AC-006-04-02]] — Given the search returns no matches, when results load, then the web app shows an empty-results message and a result count of 0 instead of an error
- [[AC-006-04-03]] — Given the user selects a tag filter, when they apply it, then the web app includes the tag filter in the search request, renders only matching notes in the selected sort order, and updates the live result count to match
