# US-004-03: ensure note data persisted via the API is never written to backup or logging destinations outside the EU

## Definition

As a **backend developer**, I want to **ensure note data persisted via the API is never written to backup or logging destinations outside the EU**, so that **prevents regulatory risk from data leakage outside audited EU storage**.

**Epic:** [[EP-004]]

## Acceptance Criteria
- [[AC-004-03-01]] — Given a note is created or edited via the API, when the record is persisted and backed up, then both primary storage and backups reside in EU regions
- [[AC-004-03-02]] — Given a logging or backup destination configured outside the EU, when the system attempts to write to it, then the write is blocked and an alert is raised
