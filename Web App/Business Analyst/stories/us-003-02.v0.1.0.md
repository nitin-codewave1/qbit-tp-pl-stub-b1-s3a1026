# US-003-02: restore (unarchive) a previously archived note via the API

## Definition

As a **team member resuming old work**, I want to **restore (unarchive) a previously archived note via the API**, so that **bring a note back to active status without data loss, supporting lifecycle KPI**.

**Epic:** [[EP-003]]

## Acceptance Criteria
- [[AC-003-02-01]] — Given an archived note with a valid id exists, when client calls unarchive endpoint for that note, then API returns 200 and note status is set to active, content unchanged
- [[AC-003-02-02]] — Given note id does not exist, when client calls unarchive endpoint, then API returns 404 with error body
- [[AC-003-02-03]] — Given note is already active, when client calls unarchive endpoint, then API returns 200 idempotently without error or state change
