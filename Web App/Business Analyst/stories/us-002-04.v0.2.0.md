# US-002-04: filter search results by one or more tags

## Definition

As a **team member narrowing results by category**, I want to **filter search results by one or more tags**, so that **quickly locates notes within a known category, improving relevance KPI for tag-based queries**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-04-01]] — Given notes tagged with a specific tag exist, when client calls search endpoint with that tag as a filter parameter, then API returns 200 with only notes containing that tag
- [[AC-002-04-02]] — Given notes exist matching both a keyword and a tag filter, when client calls search with both parameters combined, then API returns 200 with notes satisfying both conditions
- [[AC-002-04-03]] — Given a filter request referencing a tag that does not exist in the system, when client calls search endpoint with that tag, then API returns 200 with an empty result list
