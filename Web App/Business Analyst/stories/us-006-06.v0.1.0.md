# US-006-06: archive, restore or pin/unpin a note from the web app so that manage note lifecycle and ordering without calling the API directly

## Definition

As a **Team member**, I want to **archive, restore or pin/unpin a note from the web app so that manage note lifecycle and ordering without calling the API directly**, so that **manage note lifecycle without calling the API directly**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-06-01]] — Given an active note is open, when the user clicks archive, then the web app calls the archive endpoint and the note disappears from the default active list
- [[AC-006-06-02]] — Given an archived note is viewed, when the user clicks restore, then the web app calls the unarchive endpoint and the note reappears in the active list
- [[AC-006-06-03]] — Given a notes row in the list, when the user clicks its pin toggle, then the web app calls the API to set the note's pinned flag and the row moves to the top with a pin icon (or returns to its sort position when unpinned)
