# US-005-06: block any endpoint or parameter designed solely to support a native mobile client (e.g. device push tokens)

## Definition

As a **backend developer**, I want to **block any endpoint or parameter designed solely to support a native mobile client (e.g. device push tokens)**, so that **keeps the API free of mobile-specific features since no mobile app is in scope**.

**Epic:** [[EP-005]]

## Acceptance Criteria
- [[AC-005-06-01]] — Given the API endpoints are reviewed, when checked for mobile-only parameters, then none are present
- [[AC-005-06-02]] — Given a request includes a device push-token field, when submitted to any endpoint, then the API returns 400 indicating the field is unsupported
