# US-006-05: log in from the web app by requesting an email one-time code and entering it on a code-entry screen

## Definition

As a **Team member**, I want to **log in from the web app by requesting an email one-time code and entering it on a code-entry screen**, so that **sign in securely without a password and understand why a code was refused**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-05-01]] — Given the user is on the login screen and enters their email address, when they submit the email and then enter a valid 6 digits-digit code on the code-entry screen, then the web app calls the notes_api request-code endpoint, shows the code-entry screen, calls the verify-code endpoint with the entered code and signs the user in
- [[AC-006-05-02]] — Given the user has entered a wrong code 5 attempts times, when the verify-code endpoint reports the account is locked, then the web app shows a lockout error stating the account is locked for 15 minutes and disables code submission
- [[AC-006-05-03]] — Given the code was issued more than 10 minutes ago, or the resend limit of 3 resends per 10 minutes has been reached, when the user submits the code or asks for a new code, then the web app shows an expired-code error with an option to request a new code, or a resend-limit error when no more resends are allowed
