# US-006-03: edit an existing note's title or body using the web editor

## Definition

As a **Team member**, I want to **edit an existing note's title or body using the web editor**, so that **keep notes accurate from the browser**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-03-01]] — Given an existing note is opened in the editor, when the user changes the title or body and saves, then the web app calls PUT/PATCH /notes/{id} and shows the updated content
- [[AC-006-03-02]] — Given the save request returns 404, when the response is received, then the web app shows a 'note not found' message and does not apply local changes
- [[AC-006-03-03]] — Given a save request returns a field-level validation error, when the response is received, then the web app highlights the invalid field
