# US-001-02: edit an existing note's title or body via the API

## Definition

As a **Team member updating shared notes**, I want to **edit an existing note's title or body via the API**, so that **keep notes accurate without data loss, supporting reliable edit success rate**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-02-01]] — Given an existing note id and updated fields, when PUT/PATCH /notes/{id} is called, then API returns 200 with the updated note reflecting changes
- [[AC-001-02-02]] — Given a note id that does not exist, when PUT/PATCH /notes/{id} is called, then API returns 404 and no data is altered
- [[AC-001-02-03]] — Given a concurrent edit request on the same note, when two update requests are sent in quick succession, then the last accepted write wins and no fields are partially corrupted
