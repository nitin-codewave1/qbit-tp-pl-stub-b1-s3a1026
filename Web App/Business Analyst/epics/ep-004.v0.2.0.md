# EP-004: EU Data Residency Compliance

Ensure all data storage/processing infrastructure is EU-resident and auditable, avoiding regulatory risk.

**Objective:** [[OBJ-004]]

## Stories
- [[US-004-01]] — configure the database and application hosting region to an EU-only region at provisioning time
- [[US-004-02]] — retrieve a report listing the region of every data store and service used by notes_api
- [[US-004-03]] — ensure note data persisted via the API is never written to backup or logging destinations outside the EU
- [[US-004-04]] — verify that any third-party services or dependencies used by notes_api also store/process data within the EU
- [[US-004-05]] — run an automated pre-launch residency check across all environments (dev, staging, prod)
- [[US-004-06]] — access a historical log of residency audit results over time
