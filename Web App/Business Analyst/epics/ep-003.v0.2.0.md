# EP-003: Archive & Restore Lifecycle

Archive/unarchive endpoints giving notes a clear lifecycle, separating old notes from active ones without deletion or data loss.

**Objective:** [[OBJ-003]]

## Stories
- [[US-003-01]] — archive a note via the API
- [[US-003-02]] — restore (unarchive) a previously archived note via the API
- [[US-003-03]] — list only archived notes via the API
- [[US-003-04]] — list only active (non-archived) notes via the API
- [[US-003-05]] — edit or tag a note regardless of its archive state
- [[US-003-06]] — receive consistent error handling for malformed archive/unarchive requests
