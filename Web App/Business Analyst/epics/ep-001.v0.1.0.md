# EP-001: Core Note CRUD API

Endpoints to create and edit short team notes with reliable 2xx success and no data loss; serves as system-of-record for notes.

**Objective:** [[OBJ-001]]

## Stories
- [[US-001-01]] — create a new note via the API with title and body text
- [[US-001-02]] — edit an existing note's title or body via the API
- [[US-001-03]] — retrieve a single note by its id
- [[US-001-04]] — list all existing notes via the API
- [[US-001-05]] — receive clear field-level validation errors when note data is malformed
- [[US-001-06]] — have each note's creation and last-modified timestamps tracked automatically
