# EP-005: Scope Guardrails & Minimal Footprint

Enforce exactly the 5 core capabilities (create, edit, tag, search, archive) with no attachments/mobile/real-time, to keep delivery fast and maintainable.

**Objective:** [[OBJ-005]]

## Stories
- [[US-005-01]] — define the API surface with exactly 5 endpoint groups (create, edit, tag, search, archive note)
- [[US-005-02]] — reject any request payload containing file/binary attachment data on the create or edit endpoints
- [[US-005-03]] — ensure no WebSocket, SSE, or polling-for-live-updates endpoints are exposed
- [[US-005-04]] — run an automated scope-compliance test suite against every build
- [[US-005-05]] — maintain a documented out-of-scope list (attachments, mobile-specific endpoints, real-time) in the API spec
- [[US-005-06]] — block any endpoint or parameter designed solely to support a native mobile client (e.g. device push tokens)
