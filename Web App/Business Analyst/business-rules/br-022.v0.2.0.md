# BR-022

An emailed login code is valid for 10 minutes, a code can be resent at most 3 resends times per 10 minutes, and 5 attempts wrong codes lock the account for 15 minutes; the web app shows the matching error for each case

**Rationale:** Limits abuse of email one-time-code login and keeps web errors consistent with notes_api behaviour
**Enforcement:** notes_api enforces the limits on request-code and verify-code; the web app displays the returned errors
