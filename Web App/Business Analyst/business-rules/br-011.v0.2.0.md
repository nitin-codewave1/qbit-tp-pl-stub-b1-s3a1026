# BR-011

Default note list endpoint excludes archived notes unless explicitly requested

**Rationale:** Keeps active workspace view clean of clutter
**Enforcement:** List endpoint default filter is_archived=false
**Exception:** A dedicated archived-list endpoint explicitly returns only archived notes
**Epics:** [[EP-003]]
