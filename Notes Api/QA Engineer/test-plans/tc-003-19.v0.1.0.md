# TC-003-19: Keyword search pinned first

**Story:** [[US-003-01]]
**Module:** search notes by keyword across title and content
**Kind:** api

## Preconditions
Pinned and unpinned notes containing 'kwdsearch'

## Expected Result
matching notes are returned with pinned notes first, then ordered by relevance, with 200 status

## Acceptance Criteria
- notes_api:AC-003-01-01: Given notes exist matching the keyword, when GET /notes/search?q=keyword is called, then matching notes are returned with pinned notes first, then ordered by relevance, with 200 status

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create unpinned match | request | `POST /notes` | {"title":"kwdsearch plain","body":"kwdsearch kwdsearch"} |
| 2 | Create pinned match | request | `POST /notes` | {"title":"other","body":"kwdsearch","pinned":true} |
| 3 | Search | request | `GET /notes/search?q=kwdsearch` |  |
| 4 | OK | assert_status | `response` | 200 |
| 5 | Pinned first | assert_json | `$.items[0].pinned` | true |
| 6 | Unpinned second | assert_json | `$.items[1].pinned` | false |
