# TC-006-05: Editor save updates existing note

**Story:** [[US-006-02]]
**Module:** create and edit notes using an in-browser editor
**Kind:** api

## Preconditions
I open an existing note in the editor and change its body

## Expected Result
the note is updated via the API and the editor shows the updated content

## Acceptance Criteria
- notes_api:AC-006-02-02: Given I open an existing note in the editor and change its body, when I save, then the note is updated via the API and the editor shows the updated content

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | {"title":"editor edit","body":"Before"} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Save changed body | request | `PATCH /notes/{{noteId}}` | {"body":"After"} |
| 4 | OK | assert_status | `status` | 200 |
| 5 | Updated body returned | assert_json | `$.body` | After |
| 6 | Reload note in editor | request | `GET /notes/{{noteId}}` |  |
| 7 | Body persisted | assert_json | `$.body` | After |
