# TC-002-09: Unarchive restores note

**Story:** [[US-002-05]]
**Module:** unarchive a note to make it active again
**Kind:** api

## Preconditions
Archived note; Bearer {{token}}

## Expected Result
API returns 200 and the note's status changes to active with all original data preserved

## Acceptance Criteria
