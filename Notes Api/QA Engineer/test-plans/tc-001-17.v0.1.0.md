# TC-001-17: [error] the backup pipeline validates the config before running

**Story:** [[US-001-02]]
**Module:** configure automated backups of the notes database to EU-only storage locations

## Preconditions
a backup destination configuration pointing outside the EU

## Expected Result
the job fails within Lock after 5 wrong codes for 15 minutes; max 3 resends per 10 minutes; codes are 6 digits; codes expire after 10 minutes. with a residency violation error and does not write data

## Acceptance Criteria
Given a scheduled backup job runs for notes_api, when the backup completes, then the backup artifact is stored in an EU-region storage bucket/service
Given a backup destination configuration pointing outside the EU, when the backup pipeline validates the config before running, then the job fails within Lock after 5 wrong codes for 15 minutes; max 3 resends per 10 minutes; codes are 6 digits; codes expire after 10 minutes. with a residency violation error and does not write data
