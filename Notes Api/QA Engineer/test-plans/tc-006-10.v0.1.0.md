# TC-006-10: Add tag appears in note and list

**Story:** [[US-006-04]]
**Module:** add, remove, and view tags on a note from the editor
**Kind:** api

## Preconditions
Existing note

## Expected Result
the tag appears on the note in both the editor and the notes list

## Acceptance Criteria
- notes_api:AC-006-04-01: Given I am editing a note, when I add a tag and save, then the tag appears on the note in both the editor and the notes list

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | {"title":"T","body":"B"} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Add tag | request | `PATCH /notes/{{noteId}}` | {"tags":["newtag"]} |
| 4 | Tag on note | assert_json | `$.tags[0]` | newtag |
| 5 | List notes | request | `GET /notes` |  |
| 6 | Tag in list | assert_json | `$.items[?(@.id=='{{noteId}}')].tags[0]` | newtag |
