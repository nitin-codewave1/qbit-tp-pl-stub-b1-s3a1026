# TC-006-14: Unarchive returns note to default list

**Story:** [[US-006-05]]
**Module:** archive and unarchive notes from the web app
**Kind:** api

## Preconditions
Archived note

## Expected Result
the note becomes active again and reappears in the default list

## Acceptance Criteria
- notes_api:AC-006-05-02: Given an archived note is viewed in an archived-notes view, when I click unarchive, then the note becomes active again and reappears in the default list
