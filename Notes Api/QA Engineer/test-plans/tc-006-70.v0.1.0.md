# TC-006-70: Fourth code request in 10 minutes rate-limited

**Story:** [[US-006-06]]
**Module:** sign in with an email one-time code through the notes_api send and verify endpoints
**Kind:** api

## Preconditions
Fresh email address with no recent code requests

## Expected Result
the app shows a rate-limit message and sends no further code

## Acceptance Criteria
- notes_api:AC-006-06-01: Given I enter my email on the sign-in page, when I request a new code more than 3 requests within 10 minutes, then the app shows a rate-limit message and sends no further code
