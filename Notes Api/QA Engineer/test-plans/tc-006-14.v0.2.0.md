# TC-006-14: Unarchive restores note to default list

**Story:** [[US-006-05]]
**Module:** archive and unarchive notes from the web app
**Kind:** api

## Preconditions
an archived note is viewed in an archived-notes view

## Expected Result
the note becomes active again and reappears in the default list

## Acceptance Criteria
- notes_api:AC-006-05-02: Given an archived note is viewed in an archived-notes view, when I click unarchive, then the note becomes active again and reappears in the default list

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | {"title":"uiunarchive note","body":"B"} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Archive | request | `POST /notes/{{noteId}}/archive` |  |
| 4 | Click unarchive | request | `POST /notes/{{noteId}}/unarchive` |  |
| 5 | OK | assert_status | `status` | 200 |
| 6 | Active | assert_json | `$.status` | active |
| 7 | Load default list | request | `GET /notes/search?q=uiunarchive` |  |
| 8 | Back in default list | assert_json | `$.total` | 1 |
