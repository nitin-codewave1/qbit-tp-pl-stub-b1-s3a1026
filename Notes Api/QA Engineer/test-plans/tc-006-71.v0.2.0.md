# TC-006-71: Code submitted after 10 minutes is expired

**Story:** [[US-006-06]]
**Module:** sign in with an email one-time code through the notes_api send and verify endpoints
**Kind:** api

## Preconditions
I submit a one-time code more than 10 minutes after it was issued

## Expected Result
sign-in is rejected with an expired-code message

## Acceptance Criteria
- notes_api:AC-006-06-02: Given I submit a one-time code more than 10 minutes after it was issued, when I try to sign in, then sign-in is rejected with an expired-code message

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|

| 2 | Accepted | assert_status | `status` | 202 |

| 4 | Wait past the 10-minute expiry (601 seconds, or advance the test clock) | wait | `seconds` | 601 |

| 6 | Expired | assert_status | `status` | 410 |
| 7 | Message for display | assert_json | `$.message` | exists |
| 8 | Code | assert_json | `$.code` | exists |
