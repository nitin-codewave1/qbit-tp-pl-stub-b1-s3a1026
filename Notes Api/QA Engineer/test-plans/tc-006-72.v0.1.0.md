# TC-006-72: Five wrong codes lock account for 15 minutes

**Story:** [[US-006-06]]
**Module:** sign in with an email one-time code through the notes_api send and verify endpoints
**Kind:** api

## Preconditions
Fresh email with an issued code

## Expected Result
my account is locked for 15 minutes and the app shows a locked-account message

## Acceptance Criteria
- notes_api:AC-006-06-03: Given I have entered 5 wrong codes, when I try again, then my account is locked for 15 minutes and the app shows a locked-account message

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Send code | request | `POST /auth/otp/send` | {"email":"lock@example.com"} |
| 2 | Retrieve valid code from test mailbox | store | `$.testCode` | otp |
| 3 | Submit wrong code 1-5 (repeat 5 times) | request | `POST /auth/otp/verify` | {"email":"lock@example.com","code":"000000"} |
| 4 | Wrong code refused | assert_status | `response` | 415 |
| 5 | Try again with the correct code | request | `POST /auth/otp/verify` | {"email":"lock@example.com","code":"{{otp}}"} |
| 6 | Refused while locked | assert_status | `response` | 415 |
| 7 | Locked-account error code | assert_json | `$.error.code` | ACCOUNT_LOCKED |
