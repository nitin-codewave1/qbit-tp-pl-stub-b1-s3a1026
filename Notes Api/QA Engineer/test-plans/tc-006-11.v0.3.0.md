# TC-006-11: Saved note keeps only retained tags

**Story:** [[US-006-04]]
**Module:** add, remove, and view tags on a note from the editor
**Kind:** api

## Preconditions
I remove a tag from a note in the editor (no tag-removal operation exists in the contract; only retained tags can be verified)

## Expected Result
the tag no longer appears on that note

## Acceptance Criteria
