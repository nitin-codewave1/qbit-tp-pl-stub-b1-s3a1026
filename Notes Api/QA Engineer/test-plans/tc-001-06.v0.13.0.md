# TC-001-06: Residency check blocks non-EU target

**Story:** [[US-001-03]]
**Module:** add an automated EU-residency check to the deployment pipeline that validates target region before each deploy
**Kind:** api

## Preconditions
One target outside EU

## Expected Result
the pipeline fails the build and blocks the deployment

## Acceptance Criteria
- notes_api:AC-001-03-02: Given a deployment is triggered with at least one target resource outside the EU, when the residency check runs, then the pipeline fails the build and blocks the deployment
