# TC-003-04: Filter by tag returns only tagged notes

**Story:** [[US-003-02]]
**Module:** filter search results by one or more tags
**Kind:** api

## Preconditions
notes tagged 'project-x' exist

## Expected Result
only notes with that tag are returned

## Acceptance Criteria
- notes_api:AC-003-02-01: Given notes tagged 'project-x' exist, when GET /notes/search?tags=project-x is called, then only notes with that tag are returned

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create tagged note | request | `POST /notes` | {"title":"Tagged","body":"B"} |
| 2 | Store id | store | `$.id` | taggedId |
| 3 | Tag it | request | `POST /notes/{{taggedId}}/tags` | {"tags":["project-x"]} |
| 4 | Create untagged note | request | `POST /notes` | {"title":"Untagged","body":"B"} |
| 5 | Search by tag | request | `GET /notes/search?tags=project-x` |  |
| 6 | OK | assert_status | `status` | 200 |
| 7 | Every result has tag | assert_json | `$.items[*].tags` | all contain project-x |
