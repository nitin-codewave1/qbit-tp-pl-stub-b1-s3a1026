# TC-006-05: Editor update saves body via API

**Story:** [[US-006-02]]
**Module:** create and edit notes using an in-browser editor
**Kind:** api

## Preconditions
Existing note; Bearer {{token}}

## Expected Result
the note is updated via the API and the editor shows the updated content

## Acceptance Criteria
- notes_api:AC-006-02-02: Given I open an existing note in the editor and change its body, when I save, then the note is updated via the API and the editor shows the updated content

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | {"title":"T","body":"Old"} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Update body | request | `PATCH /notes/{{noteId}}` | {"body":"New body"} |
| 4 | OK | assert_status | `response` | 200 |
| 5 | Reload note | request | `GET /notes/{{noteId}}` |  |
| 6 | Updated body | assert_json | `$.body` | New body |
