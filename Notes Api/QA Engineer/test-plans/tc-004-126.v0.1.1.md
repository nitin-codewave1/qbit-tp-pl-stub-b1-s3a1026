# TC-004-126: Auth error responses documented for login endpoints

**Story:** [[US-004-03]]
**Module:** see documented error responses (4xx/5xx) for each endpoint in the spec
**Kind:** api

## Preconditions
an endpoint requires authentication/authorization or is an email one-time-code login endpoint

## Expected Result
401/403 responses are documented with expected body shape, and the send/verify login endpoints document a 415 response for more than 3 requests within 10 minutes and a locked-account response after 5 wrong codes, locked for 15 minutes

## Acceptance Criteria
- notes_api:AC-004-03-02: Given an endpoint requires authentication/authorization or is an email one-time-code login endpoint, when the spec is reviewed, then 401/403 responses are documented with expected body shape, and the send/verify login endpoints document a 415 response for more than 3 requests within 10 minutes and a locked-account response after 5 wrong codes, locked for 15 minutes
