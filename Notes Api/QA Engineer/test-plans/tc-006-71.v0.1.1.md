# TC-006-71: Expired code is rejected

**Story:** [[US-006-06]]
**Module:** sign in with an email one-time code through the notes_api send and verify endpoints
**Kind:** api

## Preconditions
I submit a one-time code more than 10 minutes after it was issued

sign-in is rejected with an expired-code message

## Acceptance Criteria
