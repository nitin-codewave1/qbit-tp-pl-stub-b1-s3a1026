# TC-006-72: Five wrong codes lock account for 15 minutes

**Story:** [[US-006-06]]
**Module:** sign in with an email one-time code through the notes_api send and verify endpoints
**Kind:** api

## Preconditions
I have entered 5 wrong codes

## Expected Result
my account is locked for 15 minutes and the app shows a locked-account message

## Acceptance Criteria
- notes_api:AC-006-06-03: Given I have entered 5 wrong codes, when I try again, then my account is locked for 15 minutes and the app shows a locked-account message

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Request code | request | `POST /auth/request-code` | {"email":"lock@example.com"} |
| 2 | Accepted | assert_status | `status` | 202 |
| 3 | Wrong code 1 of 5 (repeat through 5) | request | `POST /auth/verify-code` | {"email":"lock@example.com","code":"000000"} |
| 4 | Rejected | assert_status | `status` | 400 |
| 5 | Try again after 5 wrong codes | request | `POST /auth/verify-code` | {"email":"lock@example.com","code":"000000"} |
| 6 | Locked | assert_status | `status` | 400 |
| 7 | Locked-account message | assert_json | `$.error.message` | contains locked |
