# TC-002-17: PATCH pinned only leaves other fields unchanged

**Story:** [[US-002-02]]
**Module:** edit an existing note's title, body, or tags
**Kind:** api

## Preconditions
a PATCH containing only the pinned field

## Expected Result
API returns 200, pinned is updated, and title, body and tags are unchanged

## Acceptance Criteria
- notes_api:AC-002-02-02: Given a PATCH containing only the pinned field, when it is submitted, then API returns 200, pinned is updated, and title, body and tags are unchanged

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | {"title":"Keep","body":"Same"} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Add tag | request | `POST /notes/{{noteId}}/tags` | {"tags":["a"]} |
| 4 | OK | assert_status | `status` | 200 |
| 5 | Patch pinned only | request | `PATCH /notes/{{noteId}}` | {"pinned":true} |
| 6 | OK | assert_status | `status` | 200 |
| 7 | Pinned | assert_json | `$.pinned` | true |
| 8 | Title unchanged | assert_json | `$.title` | Keep |
| 9 | Body unchanged | assert_json | `$.body` | Same |
| 10 | Tags unchanged | assert_json | `$.tags[0]` | a |
