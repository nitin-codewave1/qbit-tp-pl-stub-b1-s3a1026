# TC-005-09: Multipart upload returns OUT_OF_SCOPE structured error

**Story:** [[US-005-04]]
**Module:** receive a clear, documented error when calling an unsupported out-of-scope endpoint (mobile-specific, attachment, or real-time)
**Kind:** api

## Preconditions
an integrator sends a multipart file upload to a notes endpoint

## Expected Result
the response returns a structured error code (e.g. OUT_OF_SCOPE) with a human-readable reason

## Acceptance Criteria
- notes_api:AC-005-04-02: Given an integrator sends a multipart file upload to a notes endpoint, when the request is validated, then the response returns a structured error code (e.g. OUT_OF_SCOPE) with a human-readable reason

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Send multipart upload | request | `POST /notes` | {"headers":{"Content-Type":"multipart/form-data; boundary=x"},"body":"--x\r\nContent-Disposition: form-data; name=\"file\"; filename=\"a.png\"\r\n\r\nabc\r\n--x--"} |
| 2 | Unsupported media type | assert_status | `status` | 415 |
| 3 | Error code | assert_json | `$.error.code` | OUT_OF_SCOPE |
| 4 | Human-readable reason | assert_json | `$.error.message` | exists |
