# TC-006-12: Duplicate tag not created

**Story:** [[US-006-04]]
**Module:** add, remove, and view tags on a note from the editor
**Kind:** api

## Preconditions
I try to add a tag that already exists on the note

## Expected Result
no duplicate tag is created and the UI reflects a single instance

## Acceptance Criteria
- notes_api:AC-006-04-03: Given I try to add a tag that already exists on the note, when I save, then no duplicate tag is created and the UI reflects a single instance
