# TC-002-06: Adding duplicate tag creates no duplicate

**Story:** [[US-002-03]]
**Module:** add or remove tags on a note
**Kind:** api

## Preconditions
a tag that already exists on the note

## Expected Result
API returns 200 without creating a duplicate tag entry

## Acceptance Criteria
- notes_api:AC-002-03-02: Given a tag that already exists on the note, when the same tag is added again, then API returns 200 without creating a duplicate tag entry

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | `API-NOTES-232390` body `{"title":"T","body":"B"}` |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Add tag first time | request | `POST /notes/{id}/tags` | `API-NOTES-359413` id={{noteId}} body `{"tags":["dup"]}` |
| 4 | OK | assert_status | `` | 200 |
| 5 | Add same tag again | request | `POST /notes/{id}/tags` | `API-NOTES-359413` id={{noteId}} body `{"tags":["dup"]}` |
| 6 | OK | assert_status | `` | 200 |
| 7 | Tag present once | assert_json | `$.tags[0]` | dup |
| 8 | No second entry | assert_absent | `$.tags[1]` |  |
