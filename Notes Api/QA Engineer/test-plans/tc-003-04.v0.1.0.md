# TC-003-04: Filter by tag returns only tagged notes

**Story:** [[US-003-02]]
**Module:** filter search results by one or more tags
**Kind:** api

## Preconditions
Notes tagged project-x and one untagged

## Expected Result
only notes with that tag are returned

## Acceptance Criteria
- notes_api:AC-003-02-01: Given notes tagged 'project-x' exist, when GET /notes/search?tags=project-x is called, then only notes with that tag are returned

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create tagged note | request | `POST /notes` | {"title":"tagged","body":"B","tags":["project-x"]} |
| 2 | Create untagged note | request | `POST /notes` | {"title":"untagged","body":"B"} |
| 3 | Filter by tag | request | `GET /notes/search?tags=project-x` |  |
| 4 | OK | assert_status | `response` | 200 |
| 5 | Every result has tag | assert_json | `$.items[*].tags` | contains project-x |
