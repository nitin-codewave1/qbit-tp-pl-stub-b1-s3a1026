# TC-001-07: Missing region metadata treated as failure

**Story:** [[US-001-03]]
**Module:** add an automated EU-residency check to the deployment pipeline that validates target region before each deploy
**Kind:** api

## Preconditions
Resource with missing region metadata

## Expected Result
the check treats it as a failure and blocks deployment rather than passing by default

## Acceptance Criteria
- notes_api:AC-001-03-03: Given a resource's region metadata is missing or unreadable, when the residency check attempts to evaluate it, then the check treats it as a failure and blocks deployment rather than passing by default
