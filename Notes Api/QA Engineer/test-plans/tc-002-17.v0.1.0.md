# TC-002-17: PATCH pinned only leaves other fields unchanged

**Story:** [[US-002-02]]
**Module:** edit an existing note's title, body, or tags
**Kind:** api

## Preconditions
Existing note with title, body, tags; Bearer {{token}}

## Expected Result
API returns 200, pinned is updated, and title, body and tags are unchanged

## Acceptance Criteria
- notes_api:AC-002-02-02: Given a PATCH containing only the pinned field, when it is submitted, then API returns 200, pinned is updated, and title, body and tags are unchanged

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note with tags | request | `POST /notes` | {"title":"T","body":"B","tags":["x"]} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | PATCH pinned only | request | `PATCH /notes/{{noteId}}` | {"pinned":true} |
| 4 | OK | assert_status | `response` | 200 |
| 5 | Pinned updated | assert_json | `$.pinned` | true |
| 6 | Title unchanged | assert_json | `$.title` | T |
| 7 | Body unchanged | assert_json | `$.body` | B |
| 8 | Tags unchanged | assert_json | `$.tags[0]` | x |
