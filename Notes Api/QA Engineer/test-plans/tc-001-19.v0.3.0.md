# TC-001-19: Non-EU backup config fails fast

**Story:** [[US-001-02]]
**Module:** configure automated backups of the notes database to EU-only storage locations
**Kind:** api

## Preconditions
Backup destination configured outside EU

## Expected Result
the job fails within 30 seconds with a residency violation error and does not write data

## Acceptance Criteria
- notes_api:AC-001-02-02: Given a backup destination configuration pointing outside the EU, when the backup pipeline validates the config before running, then the job fails within 30 seconds with a residency violation error and does not write data

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Run backup with non-EU destination | request | `POST /admin/backups/run` | {"destinationRegion":"us-east-1"} |
| 2 | Rejected | assert_status | `response` | 400 |
| 3 | Residency violation error | assert_json | `$.error.code` | RESIDENCY_VIOLATION |
| 4 | Failed within 30 seconds | assert_json | `$.durationMs` | <30000 |
| 5 | No data written | assert_json | `$.bytesWritten` | 0 |
