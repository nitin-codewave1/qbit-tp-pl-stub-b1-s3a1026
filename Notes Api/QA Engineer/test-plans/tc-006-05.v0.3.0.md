# TC-006-05: Editing body updates note

**Story:** [[US-006-02]]
**Module:** create and edit notes using an in-browser editor
**Kind:** api

## Preconditions
I open an existing note in the editor and change its body

## Expected Result
the note is updated via the API and the editor shows the updated content

## Acceptance Criteria
- notes_api:AC-006-02-02: Given I open an existing note in the editor and change its body, when I save, then the note is updated via the API and the editor shows the updated content

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | `API-NOTES-232390` body `{"title":"editupdate","body":"Old body"}` |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Save changed body | request | `PATCH /notes/{id}` | `API-NOTES-847551` id={{noteId}} body `{"body":"New body"}` |
| 4 | OK | assert_status | `` | 200 |
| 5 | Updated body returned | assert_json | `$.body` | New body |
| 6 | Reopen note | request | `GET /notes/{id}` | `API-NOTES-045877` id={{noteId}} |
| 7 | Body persisted | assert_json | `$.body` | New body |
