# TC-002-16: Edit note returns updated note

**Story:** [[US-002-02]]
**Module:** edit an existing note's title, body, or tags
**Kind:** api

## Preconditions
Existing note; Bearer {{token}}

## Expected Result
API returns 200 with the updated note and an updated timestamp

## Acceptance Criteria
- notes_api:AC-002-02-01: Given an existing note ID and valid updated fields, when PUT/PATCH to the note endpoint, then API returns 200 with the updated note and an updated timestamp

## Planned API Steps

| # | Instruction | Action | Target | Value |
|---|---|---|---|---|
| 1 | Create note | request | `POST /notes` | {"title":"Old","body":"B"} |
| 2 | Store id | store | `$.id` | noteId |
| 3 | Store original updated_at | store | `$.updated_at` | origUpdated |
| 4 | Patch title and tags | request | `PATCH /notes/{{noteId}}` | {"title":"New","tags":["a"]} |
| 5 | OK | assert_status | `response` | 200 |
| 6 | Title updated | assert_json | `$.title` | New |
| 7 | Tags updated | assert_json | `$.tags[0]` | a |
| 8 | Timestamp advanced | assert_json | `$.updated_at` | !={{origUpdated}} |
