# EP-005: Scope Guardrails (No Mobile, Attachments, Real-Time Collab)

Enforce and document exclusion of mobile apps, attachments, and real-time collaboration from notes_api scope to protect timeline and cost.

**Objective:** [[OBJ-005]]

## Stories
- [[US-005-01]] — publish an explicit out-of-scope section in the API documentation listing mobile apps, attachments, and real-time collaboration as excluded
- [[US-005-02]] — ensure no attachment or file-upload endpoint exists in notes_api
- [[US-005-03]] — ensure no real-time collaboration channel (WebSocket/SSE) exists on notes_api
- [[US-005-04]] — receive a clear, documented error when calling an unsupported out-of-scope endpoint (mobile-specific, attachment, or real-time)
- [[US-005-05]] — run an automated contract test suite verifying no mobile-specific, attachment, or real-time endpoints exist in the API surface
- [[US-005-06]] — log and classify each incoming request for mobile, attachments, or real-time collaboration against the documented exclusion list
