# EP-002: Note Lifecycle API (Create, Edit, Tag, Archive)

Implement relational-DB-backed CRUD endpoints for notes plus tagging and archive/unarchive operations, with functional test coverage. Core value: notes fully managed via API with no data loss.

**Objective:** [[OBJ-002]]

## Stories
- [[US-002-01]] — create a new note via the API with title and body
- [[US-002-02]] — edit an existing note's title, body, or tags
- [[US-002-03]] — add or remove tags on a note
- [[US-002-04]] — archive a note so it's hidden from active views but not deleted
- [[US-002-05]] — unarchive a note to make it active again
- [[US-002-06]] — retrieve a single note by ID to verify current state
