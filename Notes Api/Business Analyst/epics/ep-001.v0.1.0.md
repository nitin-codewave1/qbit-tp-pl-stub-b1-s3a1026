# EP-001: EU Data Residency Infrastructure

Provision and verify all notes_api infrastructure (DB, hosting, backups) in EU-only regions; add residency checks to deployment pipeline. Removes compliance/legal risk, a hard launch gate.

**Objective:** [[OBJ-001]]

## Stories
- [[US-001-01]] — provision the notes_api database and hosting compute exclusively in approved EU regions
- [[US-001-02]] — configure automated backups of the notes database to EU-only storage locations
- [[US-001-03]] — add an automated EU-residency check to the deployment pipeline that validates target region before each deploy
- [[US-001-04]] — generate a report listing every notes_api infrastructure component with its verified region and compliance status
- [[US-001-05]] — block the notes_api launch until the residency compliance report shows 100% EU-verified infrastructure
- [[US-001-06]] — receive an alert if any running notes_api resource drifts to or is discovered in a non-EU region after launch
