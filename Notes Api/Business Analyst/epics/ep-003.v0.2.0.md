# EP-003: Note Search

Build a search endpoint over note content/tags optimized for low latency (p95 <300ms). Lets users find notes fast instead of manual scanning.

**Objective:** [[OBJ-003]]

## Stories
- [[US-003-01]] — search notes by keyword across title and content
- [[US-003-02]] — filter search results by one or more tags
- [[US-003-03]] — receive search responses within the performance SLA under typical load
- [[US-003-04]] — combine keyword and tag filters in a single search request
- [[US-003-05]] — paginate through search results
- [[US-003-06]] — exclude archived notes from default search results
