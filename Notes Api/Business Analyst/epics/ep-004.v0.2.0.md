# EP-004: API Documentation & Integration Readiness

Publish a complete OpenAPI spec covering all endpoints so client apps (e.g., future web_app) can integrate without backend rework.

**Objective:** [[OBJ-004]]

## Stories
- [[US-004-01]] — fetch a published OpenAPI spec that documents every notes_api endpoint
- [[US-004-02]] — define request/response schemas (notes, tags, search, archive) in the OpenAPI spec with required fields and types
- [[US-004-03]] — see documented error responses (4xx/5xx) for each endpoint in the spec
- [[US-004-04]] — compute and expose a coverage metric showing % of implemented endpoints present in the published spec
- [[US-004-05]] — view example request/response payloads for search and tagging operations in the spec
- [[US-004-06]] — confirm from the spec/documentation where archived vs active note data resides and is served from
