# US-001-02: configure automated backups of the notes database to EU-only storage locations

## Definition

As a **Platform/DevOps Engineer**, I want to **configure automated backups of the notes database to EU-only storage locations**, so that **ensures backup copies don't leak data outside the EU, protecting the residency KPI**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-02-01]] — Given a scheduled backup job runs for notes_api, when the backup completes, then the backup artifact is stored in an EU-region storage bucket/service
- [[AC-001-02-02]] — Given a backup destination configuration pointing outside the EU, when the backup pipeline validates the config before running, then the job fails within 30 seconds with a residency violation error and does not write data
