# US-002-03: add or remove tags on a note

## Definition

As a **team member organizing notes by topic**, I want to **add or remove tags on a note**, so that **notes can be categorized for later retrieval, fulfilling the tagging portion of the lifecycle KPI**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-03-01]] — Given an existing note and a tag name, when a tag is added via the API, then API returns 200 and the note's tag list includes the new tag
- [[AC-002-03-02]] — Given a tag that already exists on the note, when the same tag is added again, then API returns 200 without creating a duplicate tag entry
