# US-001-03: add an automated EU-residency check to the deployment pipeline that validates target region before each deploy

## Definition

As a **Release/CI Pipeline Owner**, I want to **add an automated EU-residency check to the deployment pipeline that validates target region before each deploy**, so that **prevents non-compliant deploys from ever reaching production, acting as a hard launch gate for the residency KPI**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-03-01]] — Given a deployment is triggered with all target resources in EU regions, when the residency check runs in the pipeline, then the check passes and the deployment proceeds
- [[AC-001-03-02]] — Given a deployment is triggered with at least one target resource outside the EU, when the residency check runs, then the pipeline fails the build and blocks the deployment
- [[AC-001-03-03]] — Given a resource's region metadata is missing or unreadable, when the residency check attempts to evaluate it, then the check treats it as a failure and blocks deployment rather than passing by default
