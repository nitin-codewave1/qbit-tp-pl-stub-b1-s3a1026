# US-003-04: combine keyword and tag filters in a single search request

## Definition

As a **Team member**, I want to **combine keyword and tag filters in a single search request**, so that **get more precise results, reducing time to find the right note**.

**Epic:** [[EP-003]]

## Acceptance Criteria
- [[AC-003-04-01]] — Given q=budget and tags=finance are both supplied, when the search is executed, then only notes matching both criteria are returned
- [[AC-003-04-02]] — Given the keyword matches but the tag filter excludes all notes, when the search is executed, then an empty result set is returned
- [[AC-003-04-03]] — Given a malformed filter combination is supplied, when the search request is made, then API returns 400 with error details
