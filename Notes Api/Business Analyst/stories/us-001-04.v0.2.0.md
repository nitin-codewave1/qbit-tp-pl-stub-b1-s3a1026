# US-001-04: generate a report listing every notes_api infrastructure component with its verified region and compliance status

## Definition

As a **Compliance/Security Auditor**, I want to **generate a report listing every notes_api infrastructure component with its verified region and compliance status**, so that **provides measurable evidence of the % of infrastructure verified EU-region, supporting the launch gate sign-off**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-04-01]] — Given all notes_api resources exist and have been scanned, when the compliance report is generated, then the report lists each resource, its region, and a pass/fail residency status with an overall % compliant metric
- [[AC-001-04-02]] — Given a new resource type is added that the scanner doesn't yet recognize, when the report is generated, then the resource appears flagged as 'unverified' rather than silently omitted
