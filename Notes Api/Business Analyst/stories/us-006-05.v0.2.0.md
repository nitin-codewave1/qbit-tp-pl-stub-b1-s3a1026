# US-006-05: archive and unarchive notes from the web app

## Definition

As a **team member managing old notes**, I want to **archive and unarchive notes from the web app**, so that **hide or restore notes without calling the API directly**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-05-01]] — Given an active note is open, when I click archive, then the note is marked archived via the API and removed from the default notes list view
- [[AC-006-05-02]] — Given an archived note is viewed in an archived-notes view, when I click unarchive, then the note becomes active again and reappears in the default list
- [[AC-006-05-03]] — Given an archive or unarchive API call fails, when the action is attempted, then the web app shows an error and the note's displayed status remains unchanged
