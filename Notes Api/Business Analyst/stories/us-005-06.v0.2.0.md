# US-005-06: log and classify each incoming request for mobile, attachments, or real-time collaboration against the documented exclusion list

## Definition

As a **Product manager fielding stakeholder feature requests**, I want to **log and classify each incoming request for mobile, attachments, or real-time collaboration against the documented exclusion list**, so that **produces the countable 'rejected out-of-scope requests' metric required by the epic's KPI**.

**Epic:** [[EP-005]]

## Acceptance Criteria
- [[AC-005-06-01]] — Given a stakeholder submits a request for mobile app support, when the PM logs the request, then it is recorded with status 'rejected - out of scope' and linked to the EP-005 guardrail documentation
- [[AC-005-06-02]] — Given a request is ambiguous (e.g. 'notes with images' could imply attachments), when the PM triages it, then the request is classified against the documented exclusion criteria before a decision is logged
