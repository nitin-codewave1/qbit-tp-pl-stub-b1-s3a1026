# US-002-01: create a new note via the API with title and body

## Definition

As a **team member drafting notes**, I want to **create a new note via the API with title and body**, so that **notes are captured reliably with no data loss, supporting the CRUD functional-test KPI**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-01-01]] — Given a valid title and body payload, when POST to the notes endpoint, then API returns 201 with the created note including a unique ID, timestamps, and pinned=false by default
- [[AC-002-01-02]] — Given a valid payload with pinned=true, when POST to the notes endpoint, then API returns 201 and the stored note has pinned=true
- [[AC-002-01-03]] — Given a payload missing required title, when POST to the notes endpoint, then API returns 400 with a validation error and no note is persisted
