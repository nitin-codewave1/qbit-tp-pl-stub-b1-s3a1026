# US-003-01: search notes by keyword across title and content

## Definition

As a **Team member**, I want to **search notes by keyword across title and content**, so that **quickly locate relevant notes instead of manually scanning, enabling fast search**.

**Epic:** [[EP-003]]

## Acceptance Criteria
- [[AC-003-01-01]] — Given notes exist matching the keyword, when GET /notes/search?q=keyword is called, then matching notes are returned with pinned notes first, then ordered by relevance, with 200 status
- [[AC-003-01-02]] — Given no notes match the keyword, when the search is executed, then an empty array is returned with 200 status, not an error
- [[AC-003-01-03]] — Given the q query parameter is missing or empty, when the search request is made, then API returns 400 with a validation error message
