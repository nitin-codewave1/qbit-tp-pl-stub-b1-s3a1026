# US-006-01: view a list of my active notes

## Definition

As a **team member using the web app**, I want to **view a list of my active notes**, so that **quickly see what notes exist without calling the API directly**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-01-01]] — Given notes exist in the system, when I open the web app notes list page, then I see each note's title and an archived/active indicator
- [[AC-006-01-02]] — Given no notes exist, when I open the notes list page, then I see an empty-state message rather than an error
- [[AC-006-01-03]] — Given the API request for the notes list fails, when the list page loads, then an error message is shown instead of a blank/broken page
