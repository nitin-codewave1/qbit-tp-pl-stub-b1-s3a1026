# US-003-02: filter search results by one or more tags

## Definition

As a **Team member**, I want to **filter search results by one or more tags**, so that **narrow results to a specific topic quickly, reducing time spent scanning**.

**Epic:** [[EP-003]]

## Acceptance Criteria
- [[AC-003-02-01]] — Given notes tagged 'project-x' exist, when GET /notes/search?tags=project-x is called, then only notes with that tag are returned
- [[AC-003-02-02]] — Given a tag with no matching notes, when the search is executed, then an empty result set is returned with 200 status
- [[AC-003-02-03]] — Given the tags parameter contains invalid characters, when the search request is made, then API returns 400 with an error detail
