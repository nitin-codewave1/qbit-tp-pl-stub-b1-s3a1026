# US-001-01: provision the notes_api database and hosting compute exclusively in approved EU regions

## Definition

As a **Platform/DevOps Engineer**, I want to **provision the notes_api database and hosting compute exclusively in approved EU regions**, so that **guarantees EU data residency at launch, driving the % of infrastructure verified EU-region toward 100%**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-01-01]] — Given an infrastructure provisioning request for notes_api, when the DB and hosting resources are created, then both resources report a region within the approved EU region list
- [[AC-001-01-02]] — Given a provisioning request specifying a non-EU region, when the request is submitted, then the request is rejected and no resource is created
