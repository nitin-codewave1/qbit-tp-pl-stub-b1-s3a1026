# US-006-02: create and edit notes using an in-browser editor

## Definition

As a **team member drafting content**, I want to **create and edit notes using an in-browser editor**, so that **author and update notes without using the raw API**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-02-01]] — Given I open the editor and enter a title and body, when I save, then the note is created via the API and appears in the notes list
- [[AC-006-02-02]] — Given I open an existing note in the editor and change its body, when I save, then the note is updated via the API and the editor shows the updated content
- [[AC-006-02-03]] — Given I submit the editor with an empty title, when I try to save, then the editor shows a validation error and no API call is made
