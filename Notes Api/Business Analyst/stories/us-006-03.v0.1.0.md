# US-006-03: use a search box in the web app to search by keyword and tag

## Definition

As a **team member locating content**, I want to **use a search box in the web app to search by keyword and tag**, so that **find relevant notes without constructing API calls manually**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-03-01]] — Given I enter a keyword into the search box, when I submit the search, then the web app calls the search endpoint and displays matching notes
- [[AC-006-03-02]] — Given I filter by a tag in the search box, when I submit the search, then only notes with that tag are displayed
- [[AC-006-03-03]] — Given my search returns no results, when the search completes, then the web app shows a 'no results' message rather than an empty blank area
