# US-002-04: archive a note so it's hidden from active views but not deleted

## Definition

As a **team member cleaning up old content**, I want to **archive a note so it's hidden from active views but not deleted**, so that **old notes are retained without data loss while keeping active lists relevant, per the archive lifecycle objective**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-04-01]] — Given an active, existing note, when the archive endpoint is called, then API returns 200, marks the note archived, and its data remains intact
- [[AC-002-04-02]] — Given an already-archived note, when the archive endpoint is called again, then API returns a conflict/error response indicating it's already archived
