# US-003-06: exclude archived notes from default search results

## Definition

As a **Team member**, I want to **exclude archived notes from default search results**, so that **see only active, relevant notes by default, reducing noise and scan time**.

**Epic:** [[EP-003]]

## Acceptance Criteria
- [[AC-003-06-01]] — Given both archived and active notes exist, when a default search is executed, then only active notes are returned
- [[AC-003-06-02]] — Given include_archived=true is passed, when the search is executed, then archived notes are included in results
- [[AC-003-06-03]] — Given an invalid include_archived value is supplied, when the search request is made, then API returns 400 with an error message
