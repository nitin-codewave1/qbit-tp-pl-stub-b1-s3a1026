# US-006-04: add, remove, and view tags on a note from the editor

## Definition

As a **team member organizing notes**, I want to **add, remove, and view tags on a note from the editor**, so that **categorize notes without leaving the web app**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-04-01]] — Given I am editing a note, when I add a tag and save, then the tag appears on the note in both the editor and the notes list
- [[AC-006-04-02]] — Given I remove a tag from a note in the editor, when I save, then the tag no longer appears on that note
- [[AC-006-04-03]] — Given I try to add a tag that already exists on the note, when I save, then no duplicate tag is created and the UI reflects a single instance
