# US-002-05: unarchive a note to make it active again

## Definition

As a **team member restoring previously archived content**, I want to **unarchive a note to make it active again**, so that **archived notes remain fully recoverable, ensuring the lifecycle is reversible with no data loss**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-05-01]] — Given an archived note, when the unarchive endpoint is called, then API returns 200 and the note's status changes to active with all original data preserved
- [[AC-002-05-02]] — Given a note ID that does not exist, when the unarchive endpoint is called, then API returns 404
