# US-003-05: paginate through search results

## Definition

As a **Team member**, I want to **paginate through search results**, so that **efficiently browse large result sets without overwhelming responses, keeping search fast**.

**Epic:** [[EP-003]]

## Acceptance Criteria
- [[AC-003-05-01]] — Given more results exist than the page size, when page and limit params are supplied, then the correct subset is returned along with a total count
- [[AC-003-05-02]] — Given a page number beyond available results, when the search is executed, then an empty array is returned with 200 status
- [[AC-003-05-03]] — Given negative or non-numeric page/limit values, when the search request is made, then API returns 400 with a validation error
