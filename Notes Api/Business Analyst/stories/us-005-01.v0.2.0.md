# US-005-01: publish an explicit out-of-scope section in the API documentation listing mobile apps, attachments, and real-time collaboration as excluded

## Definition

As a **Engineering lead maintaining notes_api**, I want to **publish an explicit out-of-scope section in the API documentation listing mobile apps, attachments, and real-time collaboration as excluded**, so that **gives stakeholders a documented reference to point to when rejecting out-of-scope requests, driving the rejection-count KPI**.

**Epic:** [[EP-005]]

## Acceptance Criteria
- [[AC-005-01-01]] — Given the published API documentation, when a reader views the 'Scope' section, then mobile apps, attachments, and real-time collaboration are listed as explicitly excluded
- [[AC-005-01-02]] — Given a documentation update is proposed, when a new out-of-scope item is added or changed, then the change requires review/approval before merge
- [[AC-005-01-03]] — Given the docs build pipeline, when the Scope section is missing from a build, then the documentation build fails with a lint/validation error
