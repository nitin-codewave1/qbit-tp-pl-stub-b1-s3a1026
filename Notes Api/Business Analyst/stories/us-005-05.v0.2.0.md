# US-005-05: run an automated contract test suite verifying no mobile-specific, attachment, or real-time endpoints exist in the API surface

## Definition

As a **QA engineer responsible for notes_api regression testing**, I want to **run an automated contract test suite verifying no mobile-specific, attachment, or real-time endpoints exist in the API surface**, so that **continuously enforces the minimal-scope boundary, directly supporting measurement of the rejected-requests KPI**.

**Epic:** [[EP-005]]

## Acceptance Criteria
- [[AC-005-05-01]] — Given the CI pipeline runs, when the scope-guardrail test suite executes against the OpenAPI spec, then it passes only when zero endpoints match excluded categories (mobile, attachments, real-time)
- [[AC-005-05-02]] — Given a developer adds a new endpoint matching an excluded pattern (e.g. /attachments or /ws), when CI runs on the pull request, then the guardrail test fails and blocks the merge
