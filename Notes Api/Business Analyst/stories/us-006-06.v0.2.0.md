# US-006-06: sign in with an email one-time code through the notes_api send and verify endpoints

## Definition

As a **team member signing in to the web app**, I want to **sign in with an email one-time code through the notes_api send and verify endpoints**, so that **so that access my notes securely without a password, with the web app adapting to the new login interface change from CR-125**.

**Epic:** [[EP-006]]

## Acceptance Criteria
- [[AC-006-06-01]] — Given I enter my email on the sign-in page, when I request a new code more than 3 requests within 10 minutes, then the app shows a rate-limit message and sends no further code
- [[AC-006-06-02]] — Given I submit a one-time code more than 10 minutes after it was issued, when I try to sign in, then sign-in is rejected with an expired-code message
- [[AC-006-06-03]] — Given I have entered 5 wrong codes, when I try again, then my account is locked for 15 minutes and the app shows a locked-account message
