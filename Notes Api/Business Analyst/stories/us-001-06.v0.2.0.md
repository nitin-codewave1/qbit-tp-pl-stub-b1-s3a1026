# US-001-06: receive an alert if any running notes_api resource drifts to or is discovered in a non-EU region after launch

## Definition

As a **Platform/DevOps Engineer**, I want to **receive an alert if any running notes_api resource drifts to or is discovered in a non-EU region after launch**, so that **maintains the 100% EU-region verification KPI on an ongoing basis, not just at launch**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-06-01]] — Given a periodic residency scan runs post-launch, when all resources remain in EU regions, then no alert is raised and the scan logs a pass
- [[AC-001-06-02]] — Given a periodic residency scan runs post-launch, when a resource is found in a non-EU region (e.g., via misconfigured auto-scaling), then an alert is sent to the DevOps team immediately with resource details
