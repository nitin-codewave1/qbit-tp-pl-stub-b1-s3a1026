# US-002-06: retrieve a single note by ID to verify current state

## Definition

As a **QA engineer validating API reliability**, I want to **retrieve a single note by ID to verify current state**, so that **confirms CRUD correctness and supports the functional-test-pass-rate KPI**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-06-01]] — Given an existing note ID, when GET is called on the note endpoint, then API returns 200 with full note details including tags, archive status and the pinned flag
- [[AC-002-06-02]] — Given an ID for a deleted or never-existing note, when GET is called on that note endpoint, then API returns 404 with no partial data exposed
