# US-002-02: edit an existing note's title, body, or tags

## Definition

As a **team member updating existing work**, I want to **edit an existing note's title, body, or tags**, so that **notes stay accurate and current without losing prior content, supporting zero-data-loss lifecycle**.

**Epic:** [[EP-002]]

## Acceptance Criteria
- [[AC-002-02-01]] — Given an existing note ID and valid updated fields, when PUT/PATCH to the note endpoint, then API returns 200 with the updated note and an updated timestamp
- [[AC-002-02-02]] — Given a PATCH containing only the pinned field, when it is submitted, then API returns 200, pinned is updated, and title, body and tags are unchanged
- [[AC-002-02-03]] — Given a non-existent note ID, when PUT/PATCH to that note endpoint, then API returns 404 and no data is modified
