# US-004-04: compute and expose a coverage metric showing % of implemented endpoints present in the published spec

## Definition

As a **backend developer maintaining notes_api**, I want to **compute and expose a coverage metric showing % of implemented endpoints present in the published spec**, so that **directly measure and track the KPI for integration readiness over time**.

**Epic:** [[EP-004]]

## Acceptance Criteria
- [[AC-004-04-01]] — Given all implemented endpoints are documented, when the coverage check runs, then it reports 100% coverage
- [[AC-004-04-02]] — Given one endpoint is implemented but missing from the spec, when the coverage check runs, then it reports less than 100% and names the missing endpoint
- [[AC-004-04-03]] — Given the spec file is malformed, when the coverage check runs, then it fails with a clear parsing error rather than reporting false coverage
