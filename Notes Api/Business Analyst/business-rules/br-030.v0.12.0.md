# BR-030

Only any person with a verified email address may request, verify or receive a one-time login code by email.

**Rationale:** Under CR-125 any address that verifies can obtain a credential, which may conflict with the shared-team-workspace default. The rule stays open until decided (HANDOFF-NOTESAPI-939780).
**Enforcement:** notes_api checks login-code eligibility before it sends a code and before it verifies one.
**Exception:** None stated in the sources.
**Epics:** [[EP-006]]
