# BR-032

notes_api exposes a request-code endpoint and a verify-code endpoint for email one-time-code login. The request-code endpoint refuses requests beyond 3 requests within 10 minutes. The verify-code endpoint refuses a code that is wrong, already used, or older than 10 minutes, and refuses all verification for 15 minutes after 5 wrong codes. During a lock only verification is refused; requesting a code is not refused.

**Rationale:** CR-127 adds request and verify one-time-code endpoints with lockout, resend limits and code expiry (interface change for consumers)
**Enforcement:** Server-side on each request-code and verify-code call
**Exception:** None stated
**Epics:** [[EP-004]]
