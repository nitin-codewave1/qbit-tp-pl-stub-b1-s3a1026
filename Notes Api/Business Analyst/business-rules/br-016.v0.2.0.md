# BR-016

Calls to unsupported out-of-scope endpoints (mobile-specific, attachment, real-time) must return a clear, documented error, not a silent failure or 404 ambiguity

**Rationale:** Avoids wasted integration effort, reinforces documented scope boundary
**Enforcement:** API gateway/error-handler returns standardized out-of-scope error response
**Exception:** None
**Epics:** [[EP-005]]
