# BR-033

The verify-code endpoint answers a locked account with 415, a wrong code with 415, an expired code with 415 and an already-used code with 415. A code submitted exactly 10 minutes after issue is Codes expire after 10 minutes..

**Rationale:** Status codes and the expiry boundary for verify errors are needed by the web_app to show lockout and expiry errors.
**Enforcement:** Verify-code endpoint response mapping and OpenAPI spec
