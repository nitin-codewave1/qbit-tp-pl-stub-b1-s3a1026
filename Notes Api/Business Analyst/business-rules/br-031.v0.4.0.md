# BR-031

Access to each note follows this rule: Lock after 5 wrong codes for 15 minutes; max 3 resends per 10 minutes; codes are 6 digits; codes expire after 10 minutes..

**Rationale:** Note ownership columns and the note access rule cannot be written until this is decided. The shared-workspace default is only a placeholder (HANDOFF-NOTESAPI-981573).
**Enforcement:** Note ownership fields and the access check on every note read and write follow this rule.
**Exception:** None stated in the sources.
